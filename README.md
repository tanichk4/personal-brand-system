# personal-brand-system

The style rules for @tanii444.ka.

| File | What it is |
| --- | --- |
| `tanichka-editorial.md` | The design system: colours, fonts and the signature elements (glass pill, glow, blur dissolve, handle tag). |
| `reel-stylebook.md` | How a reel is cut, captioned, animated and mixed, built on the design system. |

Both files are exported from the Tanichka Editorial design system. Change them there first, then export here, or the next export will overwrite the change. They change as a pair.

The video editing setup reads these two files by these exact names, so don't rename or move them.
